關於我

邱芸瑄

我是一名大一學生，目前正在學習數位科技概論。 希望透過這個作品集，整理自己的學習成果， 也慢慢累積屬於自己的創作紀錄。

我喜歡繪畫和烘焙。 繪畫讓我可以自由發揮創意， 而烘焙則讓我享受從材料到成品的製作過程。 未來也希望能把自己的興趣和數位科技結合， 創作出更多有趣的作品。

🎨 繪畫

我喜歡透過繪畫表達自己的想法， 也希望持續練習不同的畫風與創作方式。

🧁 烘焙

烘焙是我喜歡的休閒活動， 從準備材料到完成作品的過程都很有成就感。

學習目標

透過數位科技概論這門課， 我希望可以逐步建立數位工具與網頁製作的基礎能力。

  • 了解數位科技的基本概念與應用。
  • 學習使用 HTML 與 CSS 製作簡單的網頁。
  • 培養整理與展示學習成果的能力。
  • 將自己的興趣與數位科技結合，創作個人作品。
  • 持續累積作品，讓自己的學習歷程更加完整。
